Personal Portfolio Website

A responsive personal portfolio website built using **HTML5** and **CSS3**. The portfolio showcases personal information, skills, projects, and contact details in a clean and modern design.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Clean and modern user interface
- About Me section
- Skills section
- Projects showcase
- Contact section
- Smooth navigation
- Organized and maintainable code structure
- Built entirely with HTML and CSS (no frameworks or JavaScript)

## Technologies Used

- HTML5
- CSS3
